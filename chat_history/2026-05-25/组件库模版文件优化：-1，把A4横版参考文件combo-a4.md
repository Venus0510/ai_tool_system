## 变更总结

### 问题
生成的报告 HTML 通过 `<link href="../../UI-lib/tokens/xxx.css">` 相对路径引用主题 CSS，导致：
- Claude 客户端预览看不到颜色
- 文件脱离项目目录后样式丢失
- 无法作为独立文件分享

### 修复内容

**规范文档（3 个文件）**：

| 文件 | 变更 |
|------|------|
| `UI-lib/.claude.md` | 规则 7 改为"主题 CSS Token 必须内联到 `<style>` 标签"；技术栈约束同步更新；组装流程明确内联要求；禁止事项增加"禁止相对路径引用 UI-lib 资源"和"报告文件必须自包含" |
| `.claude/CLAUDE.md` | 新增承诺条款："生成的报告 HTML 文件必须是自包含的最终交付物，禁止使用相对路径引用组件库资源" |
| `my-design.md` | 新增 7.4 节"报告文件自包含"设计决策；版本升至 v3.4；更新变更记录 |

**已生成的报告文件（4 个）**：

| 文件 | 变更 |
|------|------|
| `chapter-01-封面与摘要.html` | `<link>` → `<style id="token-css">` 内联完整 token CSS |
| `chapter-02-核心财务指标审计.html` | 同上 |
| `chapter-03-贷款用途与资金流向核对.html` | 同上 |
| `output/full-report.html` | 同上 |

所有文件中已确认 0 个 `link id="token-css"` 残留。CDN 依赖（Tailwind、Vue、ECharts）保持不变，因为它们使用绝对 URL，不受环境影响。

### 变更汇总

**`UI-lib/.claude.md`** — 新增规则 10「A4 页面内容不可溢出」，9 条具体子约束：

| 约束项 | 规范 |
|--------|------|
| 可用内容区 | 扣除 padding 后约 253mm × 174mm |
| 字号阶梯 | 标题 28-36px、正文 14-15px、辅助 11-13px、数据大字 40-48px |
| 列数限制 | 详情卡片 ≤ 3 列，迷你统计 ≤ 4 列 |
| 表格行数 | 单页 ≤ 12-15 行，超出分页 |
| 图表高度 | ECharts ≤ 260-280px |
| 溢出处理 | 超出时拆分为多个 `.a4-page` section，禁止堆砌 |
| 布局方式 | flex/grid 优先，仅页码用绝对定位 |
| 间距 | `gap-4` / `mb-4`，紧凑不浪费 |
| 封面例外 | `justify-center` 垂直居中，无溢出风险 |

技术栈约束和禁止事项也已同步更新。

**`.claude/CLAUDE.md`** — 新增一行：A4 横版骨架内容必须适配可视区域、不可溢出。

**`my-design.md`** — 新增 7.5 节「A4 页面内容不可溢出」设计决策，含字号/列数/表格/图表/溢出处理约束。
