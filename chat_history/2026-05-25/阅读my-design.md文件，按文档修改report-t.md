### 修复 & 精简总结

**问题根因**：页面显示 `{{ p.name }}` 原始模板语法，说明 Vue 未能编译模板。通常是 CDN 加载失败或 JS 初始化报错导致。已添加 `v-cloak` 指令 + CSS `[v-cloak] { display: none; }` 防止模板裸露。

**去掉的代码**（约 200 行）：

| 移除项 | 原因 |
|--------|------|
| File System Access API (`showDirectoryPicker`) | 浏览器兼容性差，非 HTTPS 不可用 |
| IndexedDB 目录句柄存储 (`openDB/storeHandle/getHandle/deleteHandle/verifyPermission`) | 服务于 FSA，不再需要 |
| `saveToFS` 方法 | 实时写入本地文件，已去掉 |
| `assembleReport` 方法（~80行） | 组装报告需要读本地文件，已去掉 |
| `previewReport` 方法（~35行） | 预览需要读本地文件，已去掉 |
| `_fsLinked` / `_savedPath` 状态标记 | 关联本地目录的标记 |

**新增的**：

| 新增项 | 作用 |
|--------|------|
| `exportConfig()` | 下载当前项目的 `config.json` 文件 |
| `copyConfig()` | 复制 config.json 到剪贴板 |
| `v-cloak` | 防止 Vue 编译前显示原始模板 |
