准备工作
Chrome / Edge 浏览器（Safari / Firefox 不支持文件系统访问） ·  Claude Code 工作目录设为 AIProject 根目录 ·  提前准备数据文件（csv、docx、pdf 等）
1
浏览组件库（可选）
打开 UI-lib/index.html 预览所有可用资源。已熟悉组件库可跳过此步。
2
打开报告工具，新建或导入项目
用 Chrome / Edge 打开 report-tool/index.html。
点击左侧 「新建项目」（输入名称，选择保存到 report-tool/projects/） 或 「导入项目」（选择已有项目文件夹）。
若导入的项目不在 AIProject 目录树下，顶部会显示告警条，提示 Claude Code 可能无法读取组件库。
3
配置项目
右侧编辑区分三个可折叠区块，按需填写即可。
基本设置
版式：A4 横版 / PPT 翻页 / 自由滚动
主题：商务蓝白 / RC 浅蓝 / 暗黑科技
标签：高管汇报 / 客户展示 / 内部协同 / 正式交付 / 培训材料 / 方案建议（多选）
模式：分章生成（推荐）/ 一次性
章节定义
「批量输入」自由粘贴大纲（格式不限），AI 自动理解章节结构。或切换到「逐个添加」逐章填写。每章含：
标题章节名称
描述告诉 AI 要生成什么（核心字段）
组件从组件库勾选使用
数据绑定 data/ 下的文件
关键提示
章节有 3 种状态：
待生成 — 尚未开始
草稿 — 已生成，待确认
完成 — 已确认，可组装
内容大纲写出初步想法即可，AI 会自动扩展为正式文案。不确定的数据可标记为 [待补充]。
4
保存配置
每 5 分钟自动保存，也可点击左侧 「保存配置」 手动立即保存。 配置存储在项目目录的 config.json 中，关闭浏览器不丢失，下次导入即可继续。
5
切换到 Claude Code 生成报告
在终端（工作目录为 AIProject 根目录）启动 Claude Code，说 "开始生成报告" 或项目名。
Claude 自动：扫描 projects 目录 → 读取 config.json → 读组件/骨架/主题 → 找第一个 pending 章节开始生成。
若 Claude 找不到项目，直接告知绝对路径："项目在 /Users/xxx/report-tool/projects/项目名/"
6
逐章确认与修改
Claude 生成一章后将状态更新为 "draft" 并提示。你可以对生成内容提出修改，满意后说 "继续" 或 "下一章"，Claude 将当前章标为 "done" 并处理下一章。 随时可回到工具页面查看各章状态。
7
组装最终报告
所有章节 done 后：在工具页面点击 [组装全部章节]，或在 Claude Code 中说 "组装报告"。 输出到 项目文件夹/output/.html（以 config.json 中的 projectName 命名），包含统一样式、页码、打印控制。

常见问题

必须先把数据文件放到 data/ 下吗？
建议提前放入，配置时绑定文件，Claude 生成时自动读取。也可以生成后再补充数据。
可以在配置中途关闭页面吗？
可以。每 5 分钟自动保存 + 手动保存，config.json 持久化，下次导入项目继续。
组件选择 vs 自定义布局，哪个生效？
自定义布局优先。customLayout 非空时按自定义描述生成，为空时按组件列表生成。
分章生成和一次性生成可以切换吗？
可以随时切换。长报告推荐分章模式，便于逐章精调。
Claude 找不到我的项目怎么办？
直接告诉 Claude 项目的绝对路径，Claude 会直接读取该路径下的 config.json。
可以在多台电脑上协作吗？
可以。项目文件夹独立自包含，通过 git 同步或用 U 盘拷贝，导入项目即可。
生成过程中能回工具页面改配置吗？
可以。建议等当前章完成后再改。修改后的配置在生成下一章时生效。
自定义布局模式下还需要选组件吗？
两者可同时使用。自定义布局为主，组件列表作为补充参考，帮助 AI 理解风格。
