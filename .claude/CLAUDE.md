- 禁止一轮生成超过 800 行内容，应该分轮次分批生成

## 组件库触发规则

当用户描述的需求涉及编写 HTML 页面、PPT 演示、A4 报告文件、UI 布局或数据展示页面时，**必须首先**读取并遵循 `UI-lib/.claude.md` 的约束，从 UI-lib 组件库中选取骨架、主题和组件来构建，禁止从零手写。

## 报告项目触发规则

当用户提到以下任一情况时，**必须首先**查找并读取对应报告项目的 `config.json`：

- "开始生成报告" / "继续生成" / "生成下一章" / "生成第X章"
- 指定了某个报告项目名称（如"货币基金分析报告"）
- "组装报告" / "合并章节" / "输出完整报告"

查找方式：扫描 `report-tool/projects/` 下的子目录，匹配项目名称，读取其 `config.json`。读取后严格按 `UI-lib/.claude.md` 中的分章生成流程执行。

- 用户不需要知道 config.json 的格式，通过 report-tool/index.html 可视化配置
- 你负责理解意图、匹配组件、主动建议、按配置执行
