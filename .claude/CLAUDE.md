- 禁止一轮生成超过 800 行内容，应该分轮次分批生成

## 组件库触发规则

当用户描述的需求涉及编写 HTML 页面、PPT 演示、A4 报告文件、UI 布局或数据展示页面时，**必须首先**读取并遵循 `UI-lib/.claude.md` 的约束，从 UI-lib 组件库中选取骨架、主题和组件来构建，禁止从零手写。

## 报告项目触发规则

当用户提到以下任一情况时，**必须首先**查找并读取对应报告项目的 `config.json`：

- "开始生成报告" / "继续生成" / "生成下一章" / "生成第X章"
- 指定了某个报告项目名称（如"货币基金分析报告"）
- "组装报告" / "合并章节" / "输出完整报告"

**查找 config.json 的方式（按优先级）**：
1. 优先扫描 `report-tool/projects/` 下的子目录，匹配项目名称（推荐路径，多数项目在此）
2. 若用户只说"开始生成报告"未指定项目名，且 projects/ 下有多个项目，列出项目让用户选择
3. 若只有一个项目，直接使用该项目，无需追问
4. 若未找到，询问用户提供项目文件夹的绝对路径
5. 用户也可直接给出路径（如"打开 /Users/xxx/我的项目/config.json"）

读取后严格按 `UI-lib/.claude.md` 中的分章生成流程执行。
