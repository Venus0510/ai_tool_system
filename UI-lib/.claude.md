# UI-lib 组件库约束

当用户描述的需求涉及以下任一场景时，**必须**先来 UI-lib 文件夹，参考已有组件和版式骨架来构建页面：

- 编写 HTML 页面
- 制作 PPT / 演示文稿 / Slide
- 编写报告文件（A4 报告、培训材料等）
- 任何需要 UI 布局、数据展示、可视化图表的网页

## 资源层级（由底层到上层）

```
tokens/        → 主题 CSS 变量（颜色、字体、间距）
components/    → 可复用的 Vue 组件（数据卡片、时间线、流程步骤等）
charts/        → 图表组件（柱状图、时间线图）
skeletons/     → 版式骨架（页面结构框架，含 @media print）
templates/     → 完整案例（骨架 + 组件 + 主题的组装成品）
```

## 工作流程

1. **选骨架** — 根据用户需求的输出格式，从 `skeletons/` 中选择版式骨架：
   - `a4-landscape-skeleton.html` → A4 横版报告、PDF 导出场景
   - `slide-deck-skeleton.html` → PPT 风格、Slide 翻页演示
   - `scroll-page-skeleton.html` → 自由滚动的长页面

2. **选主题** — 从 `tokens/` 中选择 CSS 主题：
   - `business-bluewhite.css` → 商务蓝白
   - `rc-lightblue.css` → RC 浅蓝
   - `dark-tech.css` → 暗黑科技

3. **选组件** — 从 `components/` 和 `charts/` 中选取合适的组件嵌入骨架：
   - `stat-card` → 数据卡片（支持 numbered/simple/accent-top 三种变体）
   - `timeline` → 时间线（支持 horizontal/vertical 两种布局）
   - `process-step` → 流程步骤（左侧/右侧色条）
   - `circle-number` → 圆形编号（四种尺寸，三种变体）
   - `badge-tag` → 标签徽章（fill/outline/accent/dot 四种风格）
   - `data-table` → 数据表格（支持斑马纹/紧凑/全边框）
   - `hero-card` → 封面卡片（light-on-dark/dark-section/stat-grid）
   - `bar-chart` → 柱状图（需 ECharts 5 CDN）
   - `timeline-chart` → 时间线图（需 ECharts 5 CDN）

4. **参考案例** — 查看 `templates/` 中的完整案例了解组装方式：
   - `combo-a4-bluewhite.html` → A4 横版 + 商务蓝白
   - `combo-slide-rc.html` → Slide 翻页 + RC 浅蓝
   - `combo-scroll-dark.html` → 滚动 + 暗黑科技
   - `pe-training-a4-bluewhite.html` → A4 培训材料完整示例

## 组件读取方式

每个组件目录包含两个文件：
- `组件名.html` — 组件的完整 HTML 源码（含样式和逻辑）
- `组件名.meta.json` — 组件的元信息（props/slots/usage/promptHint）

**读取组件时，先读 meta.json 了解组件的参数和用法，再根据需要读 HTML 源码。** meta.json 的结构：
```json
{
  "name": "stat-card",
  "label": "数据卡片",
  "description": "组件功能简述",
  "props": { "参数名": { "type": "类型", "required": true/false, "desc": "说明" } },
  "slots": ["可替换的内容区域"],
  "echarts": false,
  "usage": "示例代码片段",
  "promptHint": "适用于xxx场景"
}
```

## 生成规则

1. **替换内容，保留结构** — 复制组件 HTML 时，保留其 DOM 结构和 CSS 类名，只替换文本内容和数据；如需调整样式，通过 CSS 变量覆盖
2. **通过 meta.json 了解参数** — 每个组件的可变参数在 meta.json 中声明，根据用户需求传入对应值
3. **组装时参考模板** — templates/ 中的完整案例展示了骨架+组件+主题的正确组装方式，优先模仿其结构
4. **单文件输出** — 所有 CSS 和 JS 内联在 HTML 中，主题通过 `<link id="token-css" rel="stylesheet" href="...">` 引用相对路径
5. **自动引入依赖** — 如果使用了图表组件（echarts: true），需在页面中引入 `<script src="https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js"></script>`

## 技术栈约束

- CSS 框架：Tailwind CSS（CDN 引入）
- JS 框架：Vue 3（CDN 引入，使用 `Vue.createApp`）
- 主题系统：通过 `<link id="token-css" rel="stylesheet" href="...">` 切换 CSS Token
- 所有组件和骨架均为**单文件 HTML**，自包含样式和逻辑
- 版式骨架使用 `@page { size: A4 landscape }` 控制打印尺寸
- 所有颜色使用 CSS 变量：`color: var(--primary-500)`，`background: var(--surface)`
- @media print 中设置 `print-color-adjust: exact; -webkit-print-color-adjust: exact;` 保留打印颜色

## 禁止事项

- 不要从零手写 HTML/CSS 布局，优先复用骨架和组件
- 不要在 UI-lib 之外新建页面文件（生成的文件放在项目根目录或用户指定位置）
- 修改组件前先确认 manifest.json 中的注册信息
- 每轮生成不超过 800 行
